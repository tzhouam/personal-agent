# Recurring personal work

Use list_routines and create_routine with explicit time, calendar days and a concrete task or saved workflow. Scheduling future work requires approval and an active scheduler. A saved workflow cannot bypass tool approvals when it runs. Cancel by stable routine ID, preserve audit history, and surface delivery failures.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

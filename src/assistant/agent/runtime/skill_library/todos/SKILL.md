# Personal todos

Use list_todos before adding or completing a record. Preserve stable IDs, source URLs and due dates. Mutations use the existing locked, Git-versioned TodoStore. Never delete old records to hide a mistake. The standalone todos pipeline also publishes the website and is separately approval-gated.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

# Daily activity review

Run the nine retained phases: collect, profile, resume, digest, todos, research, website, deliver, curate. Inspect run_status and saved artifacts before resuming an interrupted run. A dry-run skips the digest email but can still publish the website, so daily and full-run aliases always require host approval. Do not mark items delivered before a transport receipt.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

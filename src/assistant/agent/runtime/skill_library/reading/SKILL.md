# Reading backlog

Use list_reading to inspect stable reading IDs. done_reading records completion; unrelated_reading records negative relevance feedback. Keep paper URLs and rationale in the reading store rather than inventing a summary. Research adds items through the retained pipeline.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

# Durable preferences and lessons

list_preferences exposes active personal rules and their provenance. learn_preference stores an explicit owner instruction; retire_preference reverses it without deleting history. self_evolve studies retained evidence and requires host approval because it changes future behavior. Personal rules take precedence over shared lessons.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

# Reusable personal procedures

Use workflows and show_workflow to inspect saved plans. create_workflow, update_workflow and retire_workflow preserve typed, Git-versioned procedures and stable IDs. The new runtime executes their steps through its ordinary tools and approvals; this catalog does not recursively launch the legacy task runner. Newly learned skill procedures require verified evidence and separate owner approval.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

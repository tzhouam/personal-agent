# Private health records

Use query_health and health_summary for computed records, then append meals, exercise and weight through typed logging actions. Estimates must remain identifiable as estimates. Preserve event dates, body facts and nutrient needs. Health data remains local and must never enter a public website or general project-memory export. Image turns can only append logging records under the host image policy.

Use the code-owned tool schema for exact parameters. A SKILL.md document cannot authorize actions, select imports, or run commands by itself.

# Résumé drafting and review

The retained resume workflow edits only facts grounded in the owner profile, applies exact text edits, and compiles when a LaTeX toolchain is available. Proposals remain local pending owner review. Publishing a résumé remains the explicit assistant approve-resume operator command; this catalog cannot approve itself.
